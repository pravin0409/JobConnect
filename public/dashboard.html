Full-Stack Architecture Specification

JobConnect is built as an individual Full-Stack application powered by a Node.js + Express REST API backend and a reactive client-side front-end communicating via asynchronous fetch() requests. Data is persistently serialized into a structured JSON file database (db.json).

📋 Tested REST API Endpoints:
GET   /api/stats — Aggregate metrics for recruiter overview
GET   /api/jobs — Search and filter job listings (title, company, type, category)
GET   /api/jobs/:id — Retrieve single job posting details
POST /api/jobs — Publish new job posting with payload validation
DELETE /api/jobs/:id — Remove job posting and associated candidate applications
POST /api/apply — Submit candidate application with regex validation
GET   /api/applications — Fetch candidate submissions list
PATCH /api/applications/:id/status — Update candidate pipeline stage (Shortlisted, Rejected, etc.)
DELETE /api/applications/:id — Delete candidate submission
